== Installation ==
Starting with YourGPT Chatbot consists of just few simple steps: installing and setting up the plugin. YourGPT Chatbot is designed to work with your site’s specific needs, so don’t forget to go through the YourGPT Chatbot first-time configuration as explained in the ‘after activation’ step!
### INSTALL YourGPT Chatbot FROM WITHIN WORDPRESS

1. Visit the plugins page within your dashboard and select ‘Add New’;
2. Search for ‘YourGPT Chatbot’;
3. Activate YourGPT Chatbot from your Plugins page;
4. Go to ‘after activation’ below.

### INSTALL YourGPT Chatbot MANUALLY

1. Upload the ‘YourGPT Chatbot’ folder to the /wp-content/plugins/ directory;
2. Activate the YourGPT Chatbot plugin through the ‘Plugins’ menu in WordPress;
3. Go to ‘after activation’ below.

### AFTER ACTIVATION

1. You should see (a notice to setup) the YourGPT Chatbot first-time configuration;
2. Visit https://yourgpt.ai/chatbot and create your chatbot. 
2. Go to Integration and copy your Widget Id and Chatbot Id for your site;
3. You’re done!

== External services ==

This plugin embeds the YourGPT chatbot widget on your site by loading `https://widget.yourgpt.ai/script.js`, which connects to YourGPT (https://yourgpt.ai) to power the chatbot. Your Widget UID is sent so the correct chatbot is displayed. See the YourGPT Privacy Policy: https://yourgpt.ai/privacy-policy and Terms: https://yourgpt.ai/terms

The plugin's settings screen in the WordPress admin (Settings → YourGPT Chatbot) embeds short demo videos from YouTube using the privacy-enhanced `youtube-nocookie.com` domain and loads the YouTube IFrame Player API from `https://www.youtube.com/iframe_api`. These are only loaded on that one admin screen, never on your public site. YouTube Privacy Policy: https://policies.google.com/privacy
